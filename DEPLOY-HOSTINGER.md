# Deploy Hostinger

1. Crie/aponte o domínio para a hospedagem.
2. Use o recurso Git da Hostinger com o repositório `https://github.com/hrcln1974/barbearia-status-teresopolis.git`, branch `main`, ou envie os arquivos para `public_html`.
3. A raiz publicada deve conter `index.php`.
4. Confirme PHP 8.1+.
5. Permita escrita em `data/` e `uploads/gallery/` se o servidor não permitir por padrão.
6. Teste `/`, `/admin.php`, login, upload, exclusão e agendamento.
7. Não publique credenciais sensíveis no Git.
